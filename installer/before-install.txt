Mockingbird runs a mock software-engineering interview on this computer. With its own model,
which is the default, nothing you say leaves it. Settings also offers a cloud provider with
your own API key; if you choose one, the text of each interview is sent to that provider, and
Settings asks you to confirm this before anything is sent. Your recordings never leave.

What it needs

  * Windows 10 or 11, 64-bit, and an internet connection the first time it starts.
  * The first start asks where the interviewer runs, and downloads nothing until you choose.
    Every download is checked against a fixed checksum before it is used.
  * On this computer: an NVIDIA graphics card with 6 GB of memory or more and a current
    driver, about 9 GB of free disk space, and a download of about 5 GB once.
  * In the cloud, for a computer without such a card: an API key from a provider (Groq's free
    tier works). Typed answers need under 100 MB of downloads; spoken answers about 2.5 GB,
    after which a short check decides whether this computer hears fast enough.

Licences

  Mockingbird's own code is MIT. The models and libraries it ships or downloads carry their
  own licences, listed in THIRD_PARTY_NOTICES.md in the install folder. Four to know about:

  * The voice model, LFM3-Audio, is under the LFM Open License v1.0. It is free to use, but
    commercial use is not licensed for organisations with US$10 million or more in annual
    revenue.
  * Delivery measurements use Parselmouth (GPL-3.0), which the first start installs from PyPI.
  * Live mode's voice detection uses sherpa-onnx, whose files contain espeak-ng (GPL-3.0).
    The GPL text is in the LICENSES folder, and THIRD_PARTY_NOTICES.md links its source.
  * Two of the optional Piper voices, HFC female and Ryan, were trained on recordings licensed
    for non-commercial use only. Settings labels them; the other voices have no such limit.

Uninstalling

  Removes the program, the models, the runtime and any stored API key. Your interviews stay in
  the "data" folder inside the install folder until you delete it.
