# What this is

Mockingbird is a practice interview. There is no employer behind it, no application attached to
it, and nobody else sees how it went. It exists so the awkward first run at a question happens
somewhere that does not count.

# Who is asking the questions

A language model, following a plan that a person wrote and approved before the interview
started. It can only ask what is on that sheet, and it decides one thing per turn: whether to
follow up on the answer, put the question another way, or move on.

# What it cannot tell you [cannot answer]

Anything about a real job. Salary, team size, the office, the hiring process, who you would
report to - there is no company here to have an answer, so it will say so rather than make one
up. If the interview was built from a job description you pasted in, it can read that
description back to you, and that is the whole of what it knows about the role.

# How answers are scored

By reading them back afterwards, not during. Each criterion is a fact about what was said -
whether the answer set the scene, said what you did, said how it turned out - and the report
shows the answer behind every judgement so you can disagree with it. There is no single grade
and no mark out of ten, because a number tells you how you did and not what to change.

Scoring runs when you open the report, which is why it takes a minute. The interview itself
never shows a judgement while it is happening.

# Where the recordings and transcripts are

In a folder on the machine running this, one directory per interview, holding the transcript
and any audio. The history page names the exact path, says how much space it is using, and
states whether anything is sent off the machine, to a cloud model or for hosting - read it
there rather than here, because that answer depends on how this copy is configured and this page
cannot know.

# Deleting an interview

The history page has a delete button on every row. It removes that interview's directory,
recordings included, and it is not reversible.

# Taking a report with you

Any report can be exported as a single file with the recordings inside it, or as data. That
copy is yours to keep, forward or print. Both are produced locally and downloaded straight to
the machine; nothing is uploaded to share them.
